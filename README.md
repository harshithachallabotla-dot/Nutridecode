NutriDecode

Description

An AI-powered nutrition tracking application that helps users monitor calories, nutrients, and food intake through food image recognition and personalized nutrition planning.

Features

- User login and registration
- BMR/TDEE calculation
- AI-based food recognition
- Calorie and nutrition tracking
- Personalized macronutrient recommendations
- Progress tracking

Technologies

- Python
- Flask
- TensorFlow (MobileNetV2)
- SQLite
- HTML
- CSS
- JavaScript
